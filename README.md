# DUSK PATROL

노을진 해안 도시 상공을 누비는 도트 그래픽 풍 3D 전투기 게임입니다. 제한 시간 격추 미션을 **무한 웨이브 캠페인**으로 개편했습니다. 적 부대를 모두 지우면 다음 웨이브로 넘어가고, 웨이브마다 강화 카드 3장 중 1장을 골라 기체를 키웁니다. 5웨이브마다 항공모함 보스가 등장합니다.

배포 파일은 `game/index.html` 하나에 모든 코드·에셋이 들어 있으며, 외부 라이브러리나 이미지 파일을 사용하지 않습니다. 소스는 역할별로 `game/src/`에 나뉘어 있고, 빌드 스크립트가 이를 한 파일로 합칩니다.

## 실행

프로젝트 폴더에서 정적 서버를 띄운 뒤 브라우저로 엽니다.

```bash
python -m http.server 5173
# 랜딩 페이지: http://127.0.0.1:5173/
# 게임만 바로 실행: http://127.0.0.1:5173/game/index.html
```

`game/index.html`을 브라우저에서 바로 열어도 동작합니다. WebGL2를 지원하는 브라우저가 필요합니다.
루트 `index.html`은 소개와 라이브 데모를 담은 랜딩 페이지이며 GitHub Pages로 배포됩니다.

- 저장소: https://github.com/jeiel85/dusk-patrol
- 라이브 데모: https://jeiel85.github.io/dusk-patrol/

## 개발

코드는 `game/src/`에서 고친 뒤 `node build.mjs`로 `game/index.html`을 다시 만들어 함께 커밋합니다(의존성 없음, Node 18 이상).
`game/src/index.html`을 브라우저로 열면 빌드 없이 분리된 소스 그대로 실행됩니다.
PR과 `main` 푸시마다 GitHub Actions가 `node build.mjs --check`로 빌드 결과가 소스와 일치하는지 확인합니다.

| 파일 | 역할 |
| --- | --- |
| `core.js` | 상수, clamp/lerp, 시드 난수, 값 노이즈, vec3·mat4, 프러스텀 판정 |
| `world.js` | 해안선·지형 높이/색, 도시 블록, 가로등, 구름 배치 |
| `gl.js` | WebGL2 컨텍스트와 프로그램·버퍼·텍스처 헬퍼, 저해상도 프레임버퍼 |
| `shaders.js` | 하늘·바다·지형·도시·구름·파티클·후처리 GLSL과 프로그램 |
| `meshes.js` | 지형 청크, 도시 인스턴스, 전투기 메시, 스프라이트 |
| `meshes2.js` | 적기(인터셉터·건십·항모) 메시와 기관포 트레이서 버퍼 |
| `font.js` | 실행 중 생성하는 5×7 비트맵 폰트와 HUD 글자 그리기 |
| `campaign.js` | 웨이브 구성, 강화 카드 풀, 난이도 곡선, 등급 계산 |
| `enemies.js` | 적 정의·AI(드론/인터셉터/건십/항모)와 적 탄환 풀 |
| `weapons.js` | 기관포(열 관리), 락온 미사일, 플레어, 배럴 롤 |
| `input.js` | 화면 맞춤, 키보드·마우스(포인터 락)·터치 입력 |
| `audio.js` | Web Audio 합성음(엔진, 바람, 전투 효과음, 웨이브/강화 징글) |
| `game.js` | 게임 상태와 시뮬레이션(기체, 피해, 파티클, 카메라, 점수) |
| `render.js` | 3D 장면 그리기와 디더·색보정 후처리 |
| `hud.js` | 타이틀·비행 HUD·웨이브 배너·강화 카드·일시정지·결과 화면 |
| `main.js` | 프레임 루프 |

스크립트는 `game/src/index.html`에 적힌 순서대로 로드되는 일반 스크립트이고 전역을 공유합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `Enter` | 시작 / 다시 비행 |
| `W` / `↑`, `S` / `↓` | 기수 올림·내림 (계속 누르면 360° 루프) |
| `A` / `D`, `←` / `→` | 고속 좌우 뱅크 선회 (반대 방향 전환 시 스냅 반전) |
| `Space` / 좌클릭 | 기관포 연사 (누르고 있으면 발사, 열이 차면 오버히트) |
| `F` / 우클릭 | 미사일 발사 (기수 앞 표적 자동 유도) |
| `X` | 플레어 (유도탄 락온 끊기) |
| `Shift` | 애프터버너 |
| `B` / `A·D` 두 번 탭 | 방향성 배럴 롤 (0.48초 고속 회피 기동, 짧은 무적) |
| `C`, `1` / `2` / `3` / `4` | 카메라 순환 / 추적·조종석(FPV)·탑다운(Overhead)·시네마틱 바로 선택 |
| `P` / `Esc` | 일시정지 / 재개 |
| `M` | 음소거 |
| `R` | 즉시 재시작 |
| `1` / `2` / `3` | 강화 카드 화면에서 카드 선택 |

### 모바일(터치)

| 터치 | 동작 |
| --- | --- |
| 화면 탭 | 시작 / 다시 비행 / 일시정지 해제 / 강화 카드 선택 |
| 왼쪽 절반 드래그 | 가상 스틱: 위·아래 = 기수, 좌·우 = 선회 |
| `FIRE` | 기관포 (누르는 동안 연사) |
| `MSL` | 미사일 |
| `FLR` | 플레어 |
| `ROLL` | 배럴 롤 |
| `BOOST` | 애프터버너 (누르는 동안) |
| `CAM` / `II` | 카메라 순환 / 일시정지 |

터치 화면이면 자동으로 터치 버튼이 나타나고, 키보드를 누르면 다시 숨겨집니다. 가로 화면에서 더 크게 보입니다.
다른 탭이나 창으로 넘어가면 비행 중인 게임은 자동으로 일시정지됩니다.

마우스는 선택 사항입니다. 비행 중 화면을 클릭하면 포인터 락이 걸려 마우스로도 조종할 수 있지만,
키보드만으로 모든 플레이가 가능합니다.

## 게임 규칙

- **웨이브**: 웨이브 시작 시 적이 순차적으로 투입됩니다. 웨이브가 오를수록 숫자와 체력이 늘고, 동시에 최대 13기까지 등장합니다.
- **적**: 드론(100점)은 순회하며 산발 사격, 인터셉터(250점)는 접근해 3연사, 건십(600점)은 유도탄과 산탄을 쏩니다. 5의 배수 웨이브에는 **항모 보스**(5000점)가 호위기와 함께 나옵니다. 항모는 피탄량이 절반 이하로 떨어지면 발사 간격이 짧아지고 드론을 투입합니다.
- **무기**:
  - 기관포는 30발/초 hitscan 사격입니다. 6 데미지, 치명타 2.2배. 약 2초 연사하면 오버히트되고, 트리거를 놓거나 잠시 식으면 다시 쏠 수 있습니다.
  - 미사일은 4발 탄창으로 시작해 2.6초마다 1발씩 자동 재장전됩니다. 기수 앞 약 26° 안의 적을 락온 표적으로 삼고, 근접 신관으로 경로상 다른 적도 맞힙니다.
  - 플레어 3발은 공중의 모든 유도탄 락온을 끊고 짧은 회피 시간을 줍니다(재충전 16초).
  - 배럴 롤은 0.48초 고속 회전하며 측면 회피 기동과 짧은 무적을 제공합니다(재충전 4초, `B` 또는 좌/우 키 두 번 탭).
- **생존**: 선체 100 + 실드 40. 실드는 6초간 피해가 없으면 초당 9씩 재생됩니다. 피해로 선체가 0이 되면 임무 종료, 지형·해수면·경계 충돌은 선체 30을 깎고 재투입됩니다. 재투입 후 1.6초 무적.
- **콤보**: 3초 안에 2기씩 격추할 때마다 배율이 오릅니다(최대 ×8). 격추 점수에 곱해지고, 사망하면 초기화됩니다.
- **웨이브 보너스**: 웨이브 클리어 시 `500 × 웨이브` 점수를 추가하고, 강화 카드 3장 중 1장을 선택한 뒤 다음 웨이브가 시작됩니다.
- **강화**: 기관포 데미지·연사속도·열용량, 선체·실드, 미사일·플레어 용량, 엔진, 치명타, 킬당 수리, 롤 쿨다운 등 11종. 같은 카드는 최대 횟수가 정해져 있습니다.
- **등급**: 결과 화면에서 웨이브 진행도·점수·최고 콤보·미사일 명중률을 종합해 S/A/B/C/D 등급을 줍니다.
- 최고 점수와 최고 웨이브는 `localStorage`에 저장되어 다음 실행에도 유지됩니다.

## 그래픽 구현

- **저해상도 렌더**: 480×270 WebGL2 프레임버퍼에 장면을 그린 뒤, CSS `image-rendering: pixelated`로 확대합니다. 기기 픽셀 기준 1~3배 사이에서는 정수 배율로 맞춰 125%·150% 배율 화면에서도 픽셀 크기가 고르고, 3배 이상(휴대폰, 큰 화면)에서는 화면을 꽉 채웁니다.
- **절차적 월드**: 160×160 높이맵 지형(고도 등고선 셰이딩), 반짝이는 파도 글린트와 2중 해안선·foam, 창문이 켜진 인스턴스 빌딩, 구형 빌보드 구름, 구름·전투기 투영 그림자, 양익 3D 비행운 리본, 모든 기체와 텍스처를 코드로 생성합니다. 바다 높이는 높이 텍스처에 부호를 담아 셰이더에서 복원합니다.
- **성능**: 지형을 8×8 청크로 나눠 프러스텀 컬링을 적용합니다(하나의 버퍼에서 보이는 청크 구간만 그림). 구름·가로등·파티클도 화면 밖이면 GPU로 보내지 않습니다. `?debug`를 붙이면 FPS와 보이는 청크 수를 표시합니다.
- **후처리**: 8×8 Bayer 디더와 채널당 10단계 양자화로 도트 질감을 유지하고, 채도·감마·비네트·split-tone 그레이딩과 피해 시 붉은 비네트를 함께 적용합니다.
- **조명**: 노을빛 방향광 + 하늘 환경광, 전투기에는 별도 밝기와 스펙큘러를 줘 역광에서도 형태가 읽히도록 했습니다.
- **HUD**: 2D 캔버스 오버레이. 5×7 비트맵 폰트를 실행 중에 생성해 캐시합니다. 레이더, 보스 체력바, 웨이브 배너, 콤보, 강화 카드, 조종석(FPV) 모드의 리벳 캐노피 아치·홀로그램 HUD 컴바이너·회전 레이더 MFD·구형 인공 수평선·기체 상태 MFD를 함께 그립니다.
- **카메라**: 추적(측면 스웨이 포함)·조종석(FPV)·탑다운(Overhead)·시네마틱 4종 시점을 부드러운 글라이드 전환으로 오갑니다. 추적 시점은 속도 보상이 있는 지수 스무딩을 사용해 루프·선회 중에도 기체가 안정적으로 프레임에 잡히며, 조종석에서 추락하면 자동으로 추적 시점으로 돌아갑니다.
- **오디오**: Web Audio API로 엔진·돌풍·기관포·미사일·배럴 롤·폭발·웨이브 클리어·강화음을 합성합니다. 외부 오디오 파일 없음.

## 파일

- `index.html` — 랜딩 페이지 (게임 소개 + 라이브 데모)
- `game/index.html` — 배포용 게임 한 파일 (빌드 결과, 직접 고치지 않음)
- `game/src/` — 게임 소스 (위 "개발" 표 참고)
- `build.mjs` — `game/src/`를 `game/index.html`로 합치는 빌드 스크립트
- `docs/cover.png` — 링크 미리보기용 커버 이미지
- `README.md` — 이 문서

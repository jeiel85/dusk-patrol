# DUSK PATROL

노을진 해안 도시 상공을 비행하는 도트 그래픽 풍 3D 전투기 게임입니다.
배포되는 게임은 `game/index.html` 파일 하나에 모든 코드·에셋이 들어 있으며, 외부 라이브러리나 이미지 파일을 사용하지 않습니다.
소스는 역할별로 `game/src/`에 나뉘어 있고, 빌드 스크립트가 이를 한 파일로 합칩니다.

## 실행

프로젝트 폴더에서 정적 서버를 띄운 뒤 브라우저로 엽니다.

```bash
python -m http.server 5173
# 랜딩 페이지: http://127.0.0.1:5173/
# 게임만 바로 실행: http://127.0.0.1:5173/game/index.html
```

`game/index.html`을 브라우저에서 바로 열어도 동작합니다. WebGL2를 지원하는 브라우저가 필요합니다.
루트 `index.html`은 소개와 라이브 데모를 담은 랜딩 페이지이며 GitHub Pages로 배포됩니다.

- 저장소: https://github.com/jeiel85/dusk-patrol
- 라이브 데모: https://jeiel85.github.io/dusk-patrol/

## 개발

코드는 `game/src/`에서 고친 뒤 `node build.mjs`로 `game/index.html`을 다시 만들어 함께 커밋합니다(의존성 없음, Node 18 이상).
`game/src/index.html`을 브라우저로 열면 빌드 없이 분리된 소스 그대로 실행됩니다.
PR과 `main` 푸시마다 GitHub Actions가 `node build.mjs --check`로 빌드 결과가 소스와 일치하는지 확인합니다.

| 파일 | 역할 |
| --- | --- |
| `core.js` | 상수, clamp/lerp, 시드 난수, 값 노이즈, vec3·mat4, 프러스텀 판정 |
| `world.js` | 해안선·지형 높이/색, 도시 블록, 가로등, 구름 배치, 드론 출현 지점 |
| `gl.js` | WebGL2 컨텍스트와 프로그램·버퍼·텍스처 헬퍼, 저해상도 프레임버퍼 |
| `shaders.js` | 하늘·바다·지형·도시·구름·파티클·후처리 GLSL과 프로그램 |
| `meshes.js` | 시작 시 한 번 만드는 지형 청크, 도시 인스턴스, 전투기·드론 메시, 스프라이트 |
| `font.js` | 실행 중 생성하는 1비트 픽셀 폰트와 HUD 글자 그리기 |
| `input.js` | 화면 맞춤, 키보드·마우스(포인터 락)·터치 입력 |
| `audio.js` | Web Audio 합성음(엔진, 바람, 애프터버너, 효과음) |
| `game.js` | 게임 상태와 시뮬레이션(파티클, 드론, 미사일, 기체, 카메라, 상태 전환) |
| `render.js` | 3D 장면 그리기와 디더·색보정 후처리 |
| `hud.js` | 타이틀·비행 HUD·경고·락온·일시정지·결과 화면 |
| `main.js` | 프레임 루프 |

스크립트는 `game/src/index.html`에 적힌 순서대로 로드되는 일반 스크립트이고 전역을 공유합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `Enter` | 시작 / 다시 비행 |
| `W` / `↑` | 기수 올림 (계속 누르면 루프, **피치 360° 회전**) |
| `S` / `↓` | 기수 내림 (역방향 루프 가능) |
| `A` / `D`, `←` / `→` | 좌우 선회 (roll 360° 가능) |
| `Shift` / `Space` | 애프터버너 |
| `F` | 미사일 발사 (표적 자동 유도) |
| `C` | 카메라 순환: 추적 → 조종석(1인칭) → 시네마틱 |
| `1` / `2` / `3` | 추적 / 조종석(1인칭) / 시네마틱 시점 바로 선택 |
| `B` | 배럴 롤 |
| `P` / `Esc` | 일시정지 / 재개 |
| `M` | 음소거 |
| `R` | 즉시 재시작 |

### 모바일(터치)

| 터치 | 동작 |
| --- | --- |
| 화면 탭 | 시작 / 다시 비행 / 일시정지 해제 |
| 왼쪽 절반 드래그 | 가상 스틱: 위·아래 = 기수 올림·내림, 좌·우 = 선회 |
| `FIRE` | 미사일 (누르고 있으면 연사) |
| `BOOST` | 애프터버너 (누르는 동안) |
| `ROLL` | 배럴 롤 |
| `CAM` / `II` | 카메라 순환 / 일시정지 |

터치 화면이면 자동으로 터치 버튼이 나타나고, 키보드를 누르면 다시 숨겨집니다. 가로 화면에서 더 크게 보입니다.
다른 탭이나 창으로 넘어가면 비행 중인 게임은 자동으로 일시정지됩니다.

마우스는 선택 사항입니다. 비행 중 화면을 클릭하면 포인터 락이 걸려 마우스로도 조종할 수 있지만,
키보드만으로 모든 플레이가 가능합니다.

## 게임 규칙

- 제한 시간 120초 동안 만 상공을 순회하는 훈련 드론 8대를 최대한 많이 격추합니다. 격추된 드론은 13~18초 뒤 다른 위치에 다시 나타납니다.
- 드론 1대 격추 시 100점, 미사일은 8발부터 시작해 3초마다 1발씩 자동 보급됩니다.
- 기수 앞 약 31° 안에 드론이 들어오면 빨간 `LOCK` 표시와 함께 경고음이 울리고, 이때 쏜 미사일은 그 드론을 추적합니다. 근접 신관이라 경로상의 다른 드론도 맞힐 수 있습니다.
- 지면에 가깝게 내려가면 `PULL UP`, 맵 경계에 다가가면 `RETURN TO PATROL AREA` 경고가 뜹니다. 지형·해수면·맵 경계에 충돌하면 2초 후 재투입됩니다.
- 마지막 10초는 타이머가 빨갛게 깜빡이며 초마다 신호음이 울립니다.
- 결과 화면에 격추 수와 명중률(격추 수 ÷ 발사한 미사일)이 나옵니다.
- 기록은 `localStorage`에 저장되어 다음 실행에도 유지됩니다.

## 그래픽 구현

- **저해상도 렌더**: 480×270 WebGL2 프레임버퍼에 장면을 그린 뒤, CSS `image-rendering: pixelated`로 확대합니다. 기기 픽셀 기준 1~3배 사이에서는 정수 배율로 맞춰 125%·150% 배율 화면에서도 픽셀 크기가 고르고, 3배 이상(휴대폰, 큰 화면)에서는 화면을 꽉 채웁니다.
- **절차적 월드**: 160×160 높이맵 지형, 해안선·foam, 창문이 켜진 인스턴스 빌딩 935동, 구름, 드론, 전투기 모두 코드로 생성합니다. 텍스처도 절차적으로 만듭니다.
- **성능**: 지형을 8×8 청크로 나눠 프러스텀 컬링을 적용합니다(하나의 버퍼에서 보이는 청크 구간만 그림). 구름·가로등·파티클도 화면 밖이면 GPU로 보내지 않습니다. `?debug`를 붙이면 FPS와 보이는 청크 수를 표시합니다.
- **후처리**: 8×8 Bayer 디더와 채널당 10단계 양자화로 도트 질감을 유지하고, 채도·감마·비네트·split-tone 그레이딩을 함께 적용합니다.
- **조명**: 노을빛 방향광 + 하늘 환경광, 전투기에는 별도 밝기와 스펙큘러를 줘 역광에서도 형태가 읽히도록 했습니다.
- **HUD**: 2D 캔버스 오버레이. 1비트 픽셀 폰트를 실행 중에 생성해 캐시하며, 조종석(1인칭) 모드에서는 캐노피 프레임과 기체 자세를 보여주는 프로젝터 링·인공 수평선을 함께 그립니다. 화면 밖에 있는 가장 가까운 드론은 가장자리 화살표와 거리로 표시됩니다.
- **카메라**: 추적 시점은 속도 보상이 있는 지수 스무딩을 사용해 루프·선회 중에도 기체가 안정적으로 프레임에 잡힙니다. 조종석에서 추락하면 자동으로 추적 시점으로 돌아갑니다.
- **오디오**: Web Audio API로 엔진·돌풍·미사일·폭발음을 합성합니다. 외부 오디오 파일 없음.

## 파일

- `index.html` — 랜딩 페이지 (게임 소개 + 라이브 데모)
- `game/index.html` — 배포용 게임 한 파일 (빌드 결과, 직접 고치지 않음)
- `game/src/` — 게임 소스 (위 "개발" 표 참고)
- `build.mjs` — `game/src/`를 `game/index.html`로 합치는 빌드 스크립트
- `docs/cover.png` — 링크 미리보기용 커버 이미지
- `README.md` — 이 문서

The mission

짧고 선명한 비행 한 판

해안선을 따라 늘어선 도시와 바다 위를 날아갑니다. 주어진 시간은 120초. 드론을 격추할 때마다 점수가 오르고, 최고 기록은 브라우저에 남습니다. 복잡한 메뉴 없이 바로 시작해 바로 끝납니다.

Flight

360도 루프와 배럴롤

기수를 계속 당기면 그대로 뒤집히며 회전합니다. 롤도 360도까지 감기고, 손을 놓으면 가장 짧은 경로로 수평을 찾습니다.

Camera

추적 · 조종석 · 시네마

123으로 시점을 바로 고르거나 C로 순환하세요. 조종석 시점에는 캐노피와 인공 수평선이 함께 표시됩니다.

World

코드로 지은 노을 도시

935동의 빌딩, 해안선과 파도, 구름, 전투기와 폭발까지 모두 절차적으로 생성됩니다. 이미지 파일 하나 없습니다.

Score

120초 스코어 어택

드론 8대를 상대로 미사일 8발로 시작합니다. 화면 밖 표적은 가장자리 화살표로 알려주고, 탄약은 자동으로 보급됩니다.

Controls

키보드만 잡으면 됩니다

마우스는 선택 사항입니다. 화면을 클릭하면 포인터 락으로 마우스 조종도 가능하지만, 키보드만으로 모든 플레이가 끝납니다.

Under the hood

하나의 HTML 파일 안에서

장면은 480×270 프레임버퍼에 그린 뒤 화면에 맞춰 정수 배율로 키웁니다. 4이웃 언샤프, Bayer 디더, 채널 양자화로 도트 질감을 살리고, 소리까지 Web Audio로 합성합니다.

  • WebGL2
  • 480×270 framebuffer
  • Ordered dithering
  • Frustum culling
  • Web Audio synthesis
  • Single HTML file
  • No dependencies
